# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Email:** [security@caseware.com](mailto:security@caseware.com)

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 3 business days and aim to provide an initial assessment within 10 business days.

## Scope

This policy covers the action source code (`action.yml`, `patch-codeql.sh`, `src/stub-tracer.c`, `bin/preload_tracer-arm64`) and the GitHub Actions workflow configurations in this repository.

Vulnerabilities in third-party components (CodeQL CLI, Temurin JDK, Ubuntu base tarball, QEMU) should be reported to their respective maintainers.
